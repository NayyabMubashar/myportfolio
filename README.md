# Nayab Mubashar — Full Stack Developer

Personal portfolio for Nayab Mubashar, a Full Stack Developer building modern, scalable web applications from responsive user interfaces to REST APIs and databases.

## Built with

- React 19 and Vite
- Component-level CSS with a shared responsive style layer
- `react-icons` for interface and technology icons

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run lint
```
